# Feature-Lifting-Explainer
An interactive, visual explainer that teaches feature lifting on a high school/undergraduate level. Uses The Pudding's [Svelte Starter template](https://github.com/the-pudding/svelte-starter) for visualizations.

**Live Site:** [LINK GOES HERE](LINK GOES HERE)


## Development
Requires Node 22.22+.

```bash
npm install
npm run dev      # local dev server
npm run build    # static build in build/
```
